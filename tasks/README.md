# Приложение «Задачи» (tasks)

## Общее описание

`tasks` — система управления задачами, объединяющая туду-лист, баг-трекер и список идей.  
Позволяет создавать задачи, назначать исполнителей, голосовать за приоритетные задачи, комментировать и отслеживать историю изменений.

## Модели

### Task
- `title` – название задачи
- `description` – описание (HTML, CKEditor)
- `task_type`, `status`, `priority` – внешние ключи на `Record` из приложения `directories`
- `author` – создатель (User)
- `assignee` – исполнитель (User, опционально)
- `created_at`, `deadline`, `completed_at` – даты
- `estimated_hours`, `actual_hours` – плановое и фактическое время
- `slug` – уникальный идентификатор (генерируется автоматически)
- `history` – версионирование через `django-simple-history`

### TaskVote
- `task` – задача
- `user` – пользователь
- `value` – +1 или -1
- Уникальность пары `(task, user)`

### TaskComment
- `task` – задача
- `author` – автор
- `text` – текст комментария
- `created_at`, `updated_at`

## Зависимости
- `directories` – гибкие справочники (типы, статусы, приоритеты)
- `django-simple-history` – версионирование
- `django-ckeditor-5` – WYSIWYG для описания

## URL-маршруты

| URL | Назначение |
|-----|-------------|
| `/tasks/` | Активные задачи (исключая «Завершена» и «Отклонена»), сортировка по голосам |
| `/tasks/all/` | Все задачи |
| `/tasks/<slug>/` | Фильтр по типу/приоритету/статусу (slug записи из справочника) |
| `/tasks/create/` | Создание задачи |
| `/tasks/<int:pk>/` | Детальная страница задачи |
| `/tasks/<int:pk>/edit/` | Редактирование |
| `/tasks/<int:pk>/delete/` | Удаление |
| `/tasks/<int:pk>/vote/` | Голосование (AJAX) |
| `/tasks/<int:pk>/history/` | История изменений |
| `/tasks/<int:pk>/comments/` | Все комментарии |

## Представления

- **`task_list`** – активные задачи (исключает завершённые и отклонённые)
- **`task_list_all`** – все задачи
- **`task_list_filtered`** – фильтр по slug (поиск в `task_types`, `task_priorities`, `task_statuses`)
- **`task_detail`** – детальная страница, форма комментария, голосование
- **`task_create`** – создание задачи (редирект на `/tasks/`)
- **`task_edit`, `task_delete`** – только автору или админу
- **`task_vote`** – AJAX-обработчик (возвращает обновлённый рейтинг)
- **`task_history`** – список версий (от новых к старым)
- **`task_comments`** – комментарии (от старых к новым) + форма добавления

## Права доступа

- Суперпользователь / staff – полный доступ
- Автор задачи – редактирование, удаление, отметка «Решена»
- Авторизованные – создание, голосование, комментарии
- Анонимы – только чтение (список, детальная страница)

## Фильтрация и сортировка

- **Фильтрация** через правую колонку (типы, приоритеты, статусы) – ссылки вида `/tasks/<slug>/`.
- **Сортировка** списков по убыванию голосов (`total_votes`).
- **Активные задачи** автоматически исключают статусы «Завершена» и «Отклонена» (используется либо slug, либо название статуса).

## Голосование

- Каждый пользователь может отдать +1
- Повторное нажатие отменяет голос.
- Рейтинг отображается в списке и на детальной странице.

## Комментарии

- Отображаются на отдельной странице `/tasks/<pk>/comments/` в хронологическом порядке.
- Форма добавления комментария – только для авторизованных.

## История изменений

- Автоматически сохраняется через `django-simple-history`.
- Доступна по `/tasks/<pk>/history/` (версии от новых к старым).

## Кнопка «Решена»

- На детальной странице (если статус не «Завершена») доступна кнопка.
- При нажатии статус задачи меняется на «Завершена», происходит редирект на `/tasks/`.
- Доступно автору задачи и администраторам.

## Пагинация

- Все списки задач разбиты по 20 записей на страницу.
- Значение задаётся константой `PAGINATE_BY = 20` в `views.py`.

## Шаблоны и стили

- Шаблоны расположены в `templates/tasks/`.
- Правая колонка на страницах задач **заменяет блок «Мой аккаунт»** на панель фильтров (типы, приоритеты, статусы).
- Базовые стили наследуются от `base.html` проекта (классы `form-input`, `btn-primary`, `content-card`).
